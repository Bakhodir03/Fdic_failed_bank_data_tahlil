# FDIC Failed Bank Data Analysis

## About the Project

This project analyzes data about failed banks in the United States.

The analysis was performed using Python and focuses on identifying
patterns in bank failures by year, state, city, and acquiring institution.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The project uses FDIC failed bank data stored in an HTML file.

The dataset contains information such as:

- Bank Name
- City
- State
- Closing Date
- Acquiring Institution
- CERT

## Analysis

The project includes analysis of:

- Bank failures by year
- Bank failures by state
- Bank failures by city
- Bank failures by region
- Acquiring institutions
- Closing trends
- CERT values

## Key Questions

- Which states had the most failed banks?
- Which cities had the most bank failures?
- How did the number of bank failures change over time?
- Which institutions acquired the failed banks?
- Which regions had the highest number of failures?
